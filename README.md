# 🚀 Project Zenith – Full-Stack Blog Management System

Project Zenith is a modern **Full-Stack Blog Management System** designed to simplify blog creation and management through a clean, responsive, and intuitive interface. Built using **Node.js, Express.js, MongoDB Atlas, HTML, CSS, and JavaScript**, the application demonstrates real-world implementation of full-stack development concepts, including RESTful API design, CRUD operations, cloud database integration, and deployment.

The project allows users to create, view, edit, and delete blog posts while ensuring a smooth user experience with a responsive interface and Dark Mode support. It serves as a practical demonstration of scalable web application development and deployment using modern technologies.

---

## ✨ Features

-  Create, edit, and delete blog posts
-  Read and manage published blogs

-  Complete CRUD functionality
-  Light & Dark Mode support
-  Responsive design across devices

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/AiswaryaVutla/project-zenith.git
```

### Navigate to the Project

```bash
cd project-zenith
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env` file in the project root.

```env
MONGODB_URI=your_mongodb_connection_string
PORT=3000
```

### Run the Application

```bash
npm start
```

Open your browser and visit:

```
http://localhost:3000
```

## 🌐 REST API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/posts` | Retrieve all blog posts |
| GET | `/posts/:id` | Retrieve a single blog post |
| POST | `/posts` | Create a new blog post |
| PATCH | `/posts/:id` | Update an existing blog |
| DELETE | `/posts/:id` | Delete a blog post |
